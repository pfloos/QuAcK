# QuAcK manual

QuAcK is a Fortran program for developing and testing electronic-structure methods. PyDuck prepares molecular integrals with PySCF and launches the Fortran driver.

- [Install and run QuAcK](quickstart.md) with an H₂ example that covers RHF, single-shot GW and standalone TDA Faddeev.
- [Check method availability](generated/methods.md) for restricted, unrestricted, generalized and other references.
- [Look up input flags and defaults](generated/inputs.md) or [find a Fortran routine](generated/routines.md).
- Read the [ground-state](electronic-structure.md), [Green's-function and response](greens-functions.md), [GW–Parquet](gw-parquet.md), and [standalone Faddeev](faddeev.md) guides.
- See [validation and contribution instructions](development.md) and the [proposed methods](roadmap.md).

For citation, funding, and contributor information, see the [project README](https://github.com/pfloos/QuAcK).
