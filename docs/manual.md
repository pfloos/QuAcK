# QuAcK manual

QuAcK is a Fortran program for developing and testing electronic-structure methods. PyDuck prepares molecular integrals with PySCF and launches the Fortran driver.

- [Install and run QuAcK](quickstart.md) with RHF and single-shot GW examples for H₂ and water.
- [Browse the method catalogue](generated/methods.md) for restricted, unrestricted, generalized and Bogoliubov drivers.
- [Look up input flags and defaults](generated/inputs.md) or [find a Fortran routine](generated/routines.md).
- Read the [ground-state](electronic-structure.md) and [Green's-function and response](greens-functions.md) guides.
- See [validation and contribution instructions](development.md).

See the [project page](project.md) for contributors, citation, and funding.
